Third-Party Notices

Street Hustle uses open-source software and temporary prototype assets during development.

PlayCanvas Engine

The game runtime uses the PlayCanvas Engine. See the PlayCanvas project for its applicable open-source license and notices.

Capacitor

The Android packaging pipeline uses Capacitor. See the Capacitor project for its applicable open-source license and notices.

Prototype humanoid assets

The development build currently references Soldier.glb, Xbot.glb and Michelle.glb from the three.js examples repository. These are being used as temporary prototype character assets.

Production release gate: Before a public commercial Google Play release, the project must confirm the redistribution/commercial terms for every included prototype asset or replace it with original or explicitly licensed Street Hustle artwork. Building an AAB does not itself complete this legal clearance.

Game content

Street Hustle story, systems and fictional world code in this repository are separate from third-party software and prototype assets.
