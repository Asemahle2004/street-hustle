Street Hustle Privacy Policy

Effective: 1 September 2026

Summary: Street Hustle currently has no user accounts, advertising SDKs or analytics SDKs. Game progress is stored locally on the device/browser.

1. Developer and contact

Street Hustle is developed by the Asemahle2004 / Street Hustle project. Privacy questions can be submitted through the project's public GitHub repository issue tracker.

Privacy/contact mechanism

2. Information the game stores

The current version stores game state such as cash, reputation, story progress, missions, settings, inventory and player position using local device/browser storage. This information is used only to save and restore gameplay.

3. Personal data

The current game does not ask for a name, email address, phone number, precise location, contacts, photos, microphone access, advertising identifier or account login. It does not intentionally transmit locally saved game progress to the developer.

4. Network access

The Google Play Android build is designed to package the game engine and current character assets inside the application. The public web build may download game-engine or prototype asset files from third-party hosting services. Those hosting providers can receive ordinary technical request information such as an IP address as part of delivering files over the internet.

5. Advertising and purchases

The current version contains no advertising SDK and no real-money in-app purchases. All money shown inside Street Hustle is fictional game currency.

6. Data retention and deletion

Local game saves remain on the device until the player resets the game, clears browser/app storage, or uninstalls the application. Because the current game has no server account, there is no remote player profile for the developer to delete.

7. Children

Street Hustle is a fictional life-simulation game containing mature themes such as financial pressure, police consequences, arrest and fictional risky choices. It is not designed specifically for young children. The final Google Play age rating will be determined through Google Play's official content-rating questionnaire.

8. Security

The Android application uses local application storage for saves. Players should keep their device and operating system updated. No method of electronic storage is guaranteed to be completely secure.

9. Changes to this policy

If future versions add online accounts, analytics, multiplayer, cloud saves, advertising, payments or other data-processing features, this policy and the Google Play Data safety declaration must be updated before release.

10. Fiction notice

Street Hustle is a fictional game. Characters, businesses, events and locations in the game are fictional or fictionalised and are not intended to make claims about real people.
